# Personal Portfolio Webpage

A responsive personal portfolio webpage built with HTML and CSS, showcasing modern web development practices and design principles.

## AI Tool Usage

**AI Tool Used:** Claude Code (Anthropic's AI assistant)

**What was AI-generated:**
- Initial HTML structure with semantic markup
- Complete CSS styling with animations and responsive design
- JavaScript for mobile hamburger menu functionality
- Color scheme and layout design
- SVG icons for social media links

**Manual Edits & Customizations:**
While this project was built with AI assistance, the following aspects were carefully reviewed and can be customized:
- Personal information (name, description, skills)
- Color scheme in CSS variables
- Social media links and contact information
- Skill descriptions and icons
- Content text throughout all sections
- Animation timing and effects
- Responsive breakpoints

## Features

### Sections Included
1. **Header** - Fixed navigation with logo and menu links
2. **Hero Section** - Eye-catching introduction with call-to-action button
3. **About Section** - Brief personal description
4. **Skills Section** - Grid layout showcasing 6+ skills with icons
5. **Footer** - Social media links and copyright information

### Responsiveness
- **Desktop (≥1024px)**: 3-column skills grid, horizontal navigation
- **Tablet (768-1023px)**: 2-column skills grid, adjusted typography
- **Mobile (≤767px)**: Single column layout, hamburger menu, optimized spacing

### Bonus Features
- ✨ CSS animations (fadeIn effects, hover transitions)
- 🎨 Unique gradient color theme (purple gradient hero)
- 🎴 Card hover effects with elevation
- 📱 Smooth scrolling navigation
- 🍔 Animated hamburger menu for mobile

## Technologies Used
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (for mobile menu)

1. Clone this repository

3. Or run with a local server:
   ```bash
   npm install
   npm run dev
   ```

## Customization Guide
To personalize this portfolio:

1. **Update Personal Info** - Edit the name, headline, and description in `index.html`
2. **Change Colors** - Modify CSS variables in `:root` selector in `portfolio.css`
3. **Add/Remove Skills** - Edit the skills grid section in HTML
4. **Update Social Links** - Replace placeholder URLs in footer with your actual profiles
5. **Modify Hero Background** - Change the gradient colors in `.hero` class
